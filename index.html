CONSUMER INSIGHT · 消费者洞察 / 内容策划 / 产品化

城缘古建用户调研与内容产品化

项目背景

城缘古建项目旨在通过内容产品化方式，让城市古建筑文化更贴近年轻人群。项目需要解决的核心问题是：目标用户对古建文化兴趣不足、内容表达枯燥、缺乏差异化体验路径。

我的职责

用户调研、深度访谈、问卷设计与分析、叙事提炼、内容产品策划。

我的行动

  1. 调研设计与执行

    设计问卷，覆盖认知、兴趣、行为、偏好四个维度，回收有效问卷 N 份；执行深度访谈 N 场，访谈对象包括游客、本地居民、文化爱好者等；结合实地走访，记录场景化观察与用户原话。

  2. 数据分析与洞察提炼

    使用 Excel / SPSS 进行描述性统计与交叉分析，识别不同人群的内容偏好差异；提炼关键洞察：用户更愿意为「故事感」「可参与」「可分享」的内容买单。

  3. 叙事提炼与内容产品化

    基于洞察提炼「六宝」核心叙事，将古建文化转化为可感知、可传播的故事体系；设计故事化导览手册（X 页），规划互动内容（打卡 / 解谜 / 音频导览等）；规划 5 条差异化城市路线，覆盖不同人群与场景。

项目成果

  • 提炼「六宝」核心叙事，形成统一的内容主线
  • 设计故事化导览手册与互动内容，提升内容吸引力
  • 规划 5 条差异化城市路线，形成可落地的内容产品方案

反思 · 可迁移能力

这个项目让我完整走了一遍「用户调研 → 洞察提炼 → 叙事构建 → 内容产品化」的流程。这套方法可以迁移到美妆快消行业：通过消费者洞察提炼品牌故事，再转化为内容营销、电商详情页、零售体验等落地形式。

BRAND & CONTENT · 品牌视觉 / 内容策划 / 用户体验

AI 熊猫「虹宝」产品身份与内容体系

项目背景

「虹宝」是一款 AI 熊猫产品，需要从零建立产品身份与内容体系，让用户不仅理解产品功能，还能对角色产生情感连接。核心挑战是：如何通过视觉、文案与交互，让一个 AI 产品拥有统一、可感知、有温度的品牌形象。

我的职责

外观美化与配色、身份卡 / 说明书 / 包装文案撰写、交互建议输出。

我的行动

  1. 视觉与配色方案

    基于产品定位与目标用户审美偏好，输出多套配色方案并完成外观美化；建立基础视觉规范，确保身份卡、说明书、包装等物料风格统一。

  2. 内容体系搭建

    撰写身份卡、说明书、包装文案，将产品功能转化为用户可理解、可感知的内容；设计开机引导语与交互话术，优化用户首次使用体验，降低认知门槛。

  3. 交互建议与原型推进

    输出 UI 与开机引导语建议，参与原型讨论；从内容和体验角度提出优化方向，推动方案进入产品原型阶段。

项目成果

  • 输出多套配色方案与全套基础视觉素材
  • 完成身份卡、说明书、包装文案等内容物料
  • UI 与开机引导语建议进入原型讨论

反思 · 可迁移能力

这个项目让我完整走了一遍「产品身份 → 视觉表达 → 内容体系 → 用户体验」的流程。这套方法可以迁移到美妆快消：为新品建立品牌视觉与包装文案，通过开箱体验、电商详情页、社媒内容等触点，完成从产品到品牌角色的表达。
